The API

Simple request.
Extraordinary result.

One API call returns a photorealistic historical newspaper front page with verified headlines, period-accurate design, and authentic newspaper style — in any of 6 languages across 30+ countries.

  • 1850 to present — any date in history
  • 30+ countries and regions
  • 6 languages including Spanish, French, German, Portuguese, Japanese
  • Broadsheet and tabloid formats
  • High resolution output — print ready
  • JSON response with headline data included
  • Then & Now and Memorial formats available
  • Webhook support for async generation
Example Request
// POST /v1/generate { "date": "1966-07-30", "country": "UK", "language": "en", "newspaper": "broadsheet", "format": "portrait" } // Response { "image_url": "https://api.inkdate...", "headline": "England Win The World Cup", "date": "July 30, 1966", "confidence": 0.98, "historical_context": "England beat West..." }
